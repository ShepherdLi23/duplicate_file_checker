# 重复文件检测工具

一个基于 Python 和 Tkinter 开发的轻量级重复文件检测工具，用于快速扫描指定文件夹中的重复文件。

程序支持 **MD5、SHA-1 和 SHA-256** 三种哈希算法，可递归扫描子文件夹，并采用“文件大小初筛 + 哈希校验”的方式判断重复文件，从而减少不必要的哈希计算，提高扫描效率。

主要功能包括重复文件分组显示、扫描进度显示、打开文件所在位置、批量选择并删除重复文件、导出 CSV 检测结果，以及重复组删除保护机制，防止误删同一组中的全部文件。

程序基于 Python 标准库开发，GUI 使用 Tkinter 实现，并支持通过 PyInstaller 打包为独立的 Windows EXE 程序，无需目标电脑额外安装 Python 环境。

适用于照片、视频、文档、下载目录以及日常文件整理等场景。
